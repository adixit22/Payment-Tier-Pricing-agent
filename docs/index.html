How it works

The agent follows the classic LLM + Tools pattern. Claude handles intent parsing and reasoning; deterministic Python functions handle the math.

Step 1

User sends a prompt

Natural language like "Quote me Elite + Creator Pro for 8 seats" or "Project revenue for 100 Starter customers."

Step 2

Claude identifies the tool

The model reads the tool schema and decides which function to call, plus what parameters to pass.

Step 3

Tool runs deterministically

Python functions do the actual math against pricing_data.py — no hallucinated numbers.

Step 4

Claude wraps the result

The agent formats the tool output into a clear, human-readable response with context and caveats.

Exposed tools

Five functions registered in the agent's tool schema. Claude decides which to call based on the user's request.

quote_package()

Returns a line-item quote for any hiring tier, creator tier, or bundle. Applies the 20% All-Access discount automatically when both tracks are selected.

project_revenue()

Takes a cohort mix (count + tier per segment) and returns total ARR, per-segment breakdown, and blended ARPA for the book of business.

recommend_tier()

Given annual hire count and campaign count, recommends the best-fit tier(s) and explains the reasoning.

list_all_bundles()

Returns the full All-Access bundle catalog with list prices, discounted prices, and savings for every valid combination.

get_tier_details()

Returns the full feature set and pricing for a specific tier — seats, postings, outreach limits, and best-fit use case.
